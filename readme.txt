Gerencie Procedimentos Operacionais Padrão dentro do painel WordPress da intranet.

== Descrição ==

Cria uma área própria para POPs, com editor de blocos do WordPress, taxonomias hierárquicas de Temas e Áreas, campos de identificação e controle, revisões nativas e histórico de versões oficiais.

== Funcionalidades da versão 1.0 ==

* Tipo de conteúdo próprio “Gestão de POPs”.
* Edição com o editor de blocos do WordPress.
* Taxonomias hierárquicas para Temas e Áreas.
* Campos para código, responsável, vigência, próxima revisão e resumo de alteração.
* Revisões nativas do WordPress.
* Versão oficial iniciada em 1.0 na primeira publicação; alterações de título, resumo ou conteúdo incrementam a versão minor (1.1, 1.2...).
* Colunas administrativas para código, versão e próxima revisão.

== Instalação ==

1. Envie a pasta `sgpop` para `wp-content/plugins/` ou instale o ZIP pelo painel.
2. Ative “SPSES - Gestão de Procedimentos Operacionais”.
3. Acesse “Gestão de POPs” no painel.
4. Configure Temas e Áreas e comece a cadastrar procedimentos.

== Observações ==

A versão 1.0 administra os documentos no painel WordPress. As permissões seguem os papéis e capacidades padrão do WordPress para edição de conteúdo. A publicação é imediata; o fluxo formal de revisão/aprovação, alertas automáticos, confirmação de leitura e área de consulta personalizada ficam como evoluções futuras.

O WordPress pode disponibilizar arquivos enviados por URL direta, dependendo da configuração do servidor. Não use anexos públicos para informação confidencial sem uma camada de proteção apropriada.
